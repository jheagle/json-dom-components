# json-dom-components

A minimal component library on [json-dom](https://github.com/jheagle/JSON-DOM): a set of base HTML element
factories (ported and reconciled from the component templates already duplicated across `quizzes`,
`workout-planner` and the website), plus richer interactive components built on top of them.

Private, not published to npm - versioned via git tags/GitHub Releases only.

See [MAIN.md](MAIN.md) for the real documentation once it exists.
